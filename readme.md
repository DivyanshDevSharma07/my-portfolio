1. IMP... href = tells the browser where a linked resource is (linking only)
          src = tells the browser where to load/embed (import js code) a resource from
2. {} in css file to edit the whole HTML at once
3. Position:
static = normal
relative = move from original spot
absolute = position inside a containing block
fixed = stays on screen acc to viewport
sticky = scrolls normally, then sticks
4. left: 50%;
   transform: translate(-50%);
left: 50% moves the element's left edge to the horizontal midpoint of its containing block.
translate(-50%) moves the element left by half of its own width.
The element's center now aligns with the containing block's center.
5. Display	Meaning
block:	Starts on a new line and takes the available width.
inline:	Stays on the same line; width and height generally don't apply.
inline-block:	Stays on the same line, but you can set width and height.
flex	Arranges children flexibly in a row or column.
grid:	Arranges children in rows and columns.
none	Hides the element and removes its space from the layout.
7. justify-content → aligns items horizontally.
align-items → aligns items vertically.
